# Resident survey (build this in Google Forms)

Anonymous. Do not ask for name or room number. Share with as many residents as you can reach; record how many were sent and how many replied.

1. Which block do you live in? (list your blocks)
2. Which year are you in? (1 / 2 / 3 / 4 / other)
3. In the last month, did you face a problem in the hostel? (Yes / No)
4. If yes, which kinds? (tick all: plumbing, electrical, Wi-Fi, mess/food, cleaning, security, furniture, other)
5. How did you report it? (verbally to warden / written register / phone call / messaging group / did not report / other)
6. Did you receive any acknowledgement? (Yes / No)
7. Did you know the status of your most recent complaint? (Yes / No / Never complained)
8. How long did the most recent complaint take to resolve? (same day / 1-3 days / 4-7 days / more than a week / never resolved / not applicable)
9. Have you ever chosen not to report a problem because you thought nothing would happen? (Yes / No)
10. Would you use a phone-friendly complaint system? (Yes / Maybe / No)
11. What one thing would improve complaint handling the most? (open text)

## How to report the results
- State n (number of responses) and the response rate.
- Report each answer as count and percentage of valid answers, for example "31 of 52 (60%)".
- Copy the numbers straight from the Google Forms summary. Do not round up or reword them to look better.
- Say honestly what the sample can and cannot tell you (for example, a single hostel, voluntary responses).
